# References

This file lists the sources behind the facts in this course: each framework's documentation, release posts
and source code, the web standards and proposals the chapters rely on, and the benchmarks, surveys and
download statistics used to compare the tools. Use it to check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the Internet
Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or changes). Links into
source files on GitHub point at a fixed release tag or commit, and their archived copy is in
[Software Heritage](https://www.softwareheritage.org/), an archive of public source code. Where no snapshot
exists, the entry says "archived: none available".
Console output, measurements (bundle sizes, line counts, build times) and test results shown in the chapters
come from running the course's own code with the versions listed in the [README](README.md), and aren't
listed here. Neither are links to the course's own code or to its companion courses.
